# Cryptography & Network Security Exam Project

## Project Overview
This repository contains a risk assessment, a Python-based file security toolkit (encryption & hashing), and firewall filtering test results for the Polytechnic Institute network.

## Repository Structure
- `security_toolkit.py`: Main Python script for file encryption, decryption, and SHA-256 integrity verification.
- `risk_assessment.md`: Risk assessment and mitigation strategy.
- `filter_tests.md`: Documented iptables configuration and test output.
- `report.tex`: LaTeX source code for the technical report.
